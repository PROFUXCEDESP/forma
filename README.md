# Forma — Cartões digitais

Projeto de landing page responsiva inspirado na referência visual enviada.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Para desenvolvimento, recomenda-se usar a extensão Live Server do VS Code.

## Estrutura
- `index.html` — estrutura semântica e conteúdo.
- `styles.css` — identidade visual, mockups CSS e breakpoints responsivos.
- `script.js` — menu mobile acessível e animações GSAP/ScrollTrigger.

## Tecnologias
- HTML5 semântico
- CSS3 (Grid, Flexbox, clamp, media queries e reduced motion)
- JavaScript vanilla
- GSAP 3 + ScrollTrigger via CDN
- Google Fonts: Manrope e DM Sans

## Observações
Os mockups de cartões, QR Codes, telas e smartphones foram construídos com HTML/CSS para manter o projeto leve e adaptável. As bibliotecas GSAP e as fontes do Google são carregadas por CDN, portanto precisam de conexão com a internet para carregar.
